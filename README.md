# Eenhoornrekenen

Een rekenspel als installeerbare web-app (PWA), statisch gehost via GitHub Pages.

Online op https://veewee.github.io/eenhoornrekenen/

Bij elke wijziging moet de cacheversie in `sw.js` omhoog (bv. `eenhoorn-v1` naar `eenhoorn-v2`), anders blijven geinstalleerde toestellen de oude versie tonen.
