# Eenhoornrekenen

Een gegenereerde app voor het automatiseren van basisrekenen: plus en min tot 20 en de tafels van 0 tot 10, met oefenrondes en een tempomodus. Het is een installeerbare web-app (PWA) zonder build-stap, gehost via GitHub Pages.

Online op https://veewee.github.io/eenhoornrekenen/

Elke push naar main wordt automatisch getest en gepubliceerd. De cacheversie in `sw.js` wordt daarbij vervangen door de commit-hash, dus je hoeft ze niet zelf op te hogen.
